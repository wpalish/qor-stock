# Public checking surface — current implementation record

This record documents the inherited Operate surface. It is not a selected comp, a newly approved visual world or a claim of a comparative design ceiling.

The entry surface uses the shared shell, then a product/variant heading, explanatory copy, a white bordered form containing quantity and delivery zone, the teal checking action, and supporting copy. Public navigation has no buttons, but its shared strip remains. The result replaces that form with a heading, request identifier, quantity, outcome content, saved source details and repeat action. The preliminary-estimate branch shows the immutable saved arithmetic; the manual-check branch shows reasons and no amount. The result heading receives programmatic focus after rendering. See `DESIGN.md` for exact tokens and the implemented CSS cascade.

The operator list uses the same shell with section navigation, list controls/search/archive toggle, a scrollable table and calculation/control summaries. The saved request editor shows the original check and optional full snapshot before processing controls. Snapshot labels remain original after source renames; new requests use current source names.
