# QorStock

Наличие товара и доставка по свежим ручным данным: предварительная оценка или запрос оператору с неизменным снимком. Оригинальный ограниченный продукт 0.1 по сценарию референса Tidio #2; не копия платформы или её кода.

## Рабочий процесс

Администратор публикует SKU/вариант, цену KZT, остаток, время проверки и срок свежести 1–168 часов. Зоны задают тариф, минимальную сумму товаров и ориентир доставки. Покупатель открывает ссылку товара и выбирает количество/зону. Свежие сведения и достаточный остаток дают сумму товаров плюс доставку. Нехватка, истечение срока или минимум зоны сохраняют запрос для ручной проверки без итоговой суммы.

В кабинете запрос ищется по номеру. Сотрудник меняет статус обработки и примечание. Исходные ссылки, количество, результат и снимок неизменны; изменение каталога не переписывает историю. Закрытые источники не принимают новые запросы. Истечение времени не блокирует историю и восстановление.

## Самостоятельный запуск

Нужен Node.js >=24.15 <25 со встроенным node:sqlite. Внешних npm-зависимостей нет.

1. Задайте уникальный WORK_ADMIN_PASSWORD длиной 14–200 символов. WORK_ADMIN_USER по умолчанию admin. Пароль не помещать в Git.
2. Выполните `npm start`. По умолчанию http://127.0.0.1:8792; PORT и PUBLIC_ORIGIN задают порт и точный адрес приложения.
3. Войдите, заведите товары и зоны. Публичная ссылка доступна в редакторе товара; нужны опубликованный товар и хотя бы одна опубликованная зона.

DATABASE_PATH задаёт SQLite, по умолчанию .data/workspace.sqlite. Синтетические данные и общие пароли в продукт не включены.

## Данные и границы

Одна организация и общая рабочая область сотрудников, без клиентской/филиальной изоляции. Администратор управляет каталогом/доставкой/аккаунтами; оператор обрабатывает запросы. Сессии HttpOnly/SameSite, пароли scrypt, CSRF/Origin, версия и журнал. Нет reset/revoke UI; администрирование доступа требует владельца. Это не сертификат безопасности. Публичному серверу нужны отдельный HTTPS hostname/reverse proxy, резервирование и правила хранения. Порты не изолируют cookies: разные недоверенные приложения не размещайте на одном hostname.

JSON-копия восстанавливает рабочие данные в пустую базу того же продукта, без аккаунтов и журнала. Она не подписана и не удостоверяет подлинность истории. Полная копия: остановить сервер и скопировать каталог базы вместе с существующими WAL/SHM; затем проверить запуск и прежние записи. Не копировать только основной файл живого SQLite. Непустая база не заменяется.

Нет AI/живого чата/семантики, интеграций со складом/сайтом/WhatsApp, заказа, оплаты, резерва или списания остатков. Один ручной остаток может показываться нескольким посетителям. Только KZT, без конвертации. Доставка — ориентир после подтверждения магазином, без календаря перевозчика. Публичный посетитель не читает чужие запросы/кабинет; защищённого продолжения диалога нет, номер передаётся сотруднику отдельно.

GitHub публикует код, а не сервер. Подтверждённых клиентов, спроса и выручки нет. [10 потенциальных компаний/партнёров](docs/buyers.json) — гипотезы. [Узкий пилот](docs/offer.md).
